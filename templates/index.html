Manual DAA Algorithms Compared

Core string-matching algorithms implemented from scratch in pure Python without reliance on built-in search methods.

Brute Force O(N × M)
1. Naive Pattern Matching

Slides the pattern window over the text one character at a time, checking every character sequentially. Simple but incurs worst-case performance on repetitive inputs.

  • Best Time: O(N)
  • Worst Time: O(N × M)
  • Space: O(1)
Rolling Hash O(N + M) Avg
2. Rabin-Karp Algorithm

Computes a numerical fingerprint using rolling hash. Character verification occurs only when hashes match, eliminating non-matching windows in O(1) rolling time.

  • Average Time: O(N + M)
  • Worst Time: O(N × M)
  • Space: O(1)
Deterministic O(N + M) Best
3. Knuth-Morris-Pratt (KMP)

Precomputes an LPS (Longest Proper Prefix which is also Suffix) array. Avoids backtracking in the text completely when a mismatch occurs.

  • Best/Avg Time: O(N)
  • Worst Time: O(N + M)
  • Space: O(M)

How PlagScan Works

A fair, step-by-step pipeline ensuring transparent algorithmic comparisons.

1
Text Normalization

Both files are lowercased and stripped of irregular whitespace and punctuation differences.

2
Word Shingling

Compared text is segmented into overlapping k-word shingles (default 5-word phrases).

3
Algorithm Search

Naive, Rabin-Karp, or KMP searches each shingle against reference text; execution time is measured.

4
Deduplicated Similarity

Unique matched tokens are tracked to calculate containment percentage without double counting.
