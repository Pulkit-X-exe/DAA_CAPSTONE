DAA String Matching Algorithms Reference
Knuth-Morris-Pratt (KMP) Algorithm

Precomputes an LPS (Longest Proper Prefix which is also a Suffix) array to avoid ever decrementing the text index pointer upon mismatch.

  • Time Complexity: Preprocessing O(M), Search O(N) → Total O(N + M)
  • Space Complexity: O(M) for the LPS array
  • Key Advantage: Text index never moves backwards (strictly deterministic runtime).
Rabin-Karp Algorithm (Rolling Hash)

Computes numerical fingerprints for sliding windows. Incurs O(1) rolling hash transition and verifies characters only upon hash match.

  • Time Complexity: Average O(N + M), Worst O(N × M) (hash collisions)
  • Space Complexity: O(1) auxiliary memory
  • Collision Resolution: Character-by-character check upon hash equality to filter spurious hits.
Naive Brute-Force Pattern Matching

Slides the pattern window one index at a time, testing all characters from index 0 to (N - M).

  • Time Complexity: Best O(N), Worst O(N × M)
  • Space Complexity: O(1)
  • Limitation: Incurs redundant comparisons when text has repeating patterns (e.g., "AAAAAB").
